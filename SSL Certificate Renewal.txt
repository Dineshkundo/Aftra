## 🏗️ Architecture

### 🔐 TLS Flow

```
User (Browser)
      ↓
Public DNS
      ↓
NGINX Ingress Controller (TLS TERMINATION)
      ↓
Kubernetes Service
      ↓
Application Pods
```

---

## 🧠 Key Insight

> SSL is NOT handled by VM NGINX
> SSL is handled at **Kubernetes Ingress via TLS Secret**

## 🔐 Kubernetes TLS Secret

### Secret Structure

```yaml
type: kubernetes.io/tls
data:
  tls.crt  # Certificate (base64)
  tls.key  # Private key (base64)
```

---

## ⚙️ Implementation Steps

---

### 🟢 Step 1: Verify Existing Certificate

```bash
kubectl get secret wildcard-secret -n codadev \
-o jsonpath="{.data.tls\.crt}" | base64 -d | openssl x509 -noout -dates
```

---

### 🟢 Step 2: Update TLS Secret

```bash
kubectl create secret tls wildcard-secret \
  --cert=/home/jenkinsadmin/aftra-new-certificates-2026/fullchain.crt \
  --key=/home/jenkinsadmin/aftra-certificates-2026/_.afmsagaftrafund.org.private.key \
  -n <namespace> \
  --dry-run=client -o yaml | kubectl apply -f -
```

---

### 🟢 Step 3: Verify Updated Secret

```bash
kubectl get secret wildcard-secret -n <namespace> \
-o jsonpath="{.data.tls\.crt}" | base64 -d | openssl x509 -noout -dates
```

---

### 🟢 Step 4: Validate via Domain

```bash
openssl s_client -connect domain:443 | openssl x509 -noout -dates
```

## ⚠️ Issues Faced & Fixes

---

### ❌ Issue 1: Certificate not reflecting

**Cause:**

* Updated VM NGINX instead of Kubernetes Ingress

**Fix:**

* Identified TLS termination at ingress level

---

### ❌ Issue 2: Wrong server debugging

```
localhost → NEW cert
domain → OLD cert
```

**Cause:**

* DNS pointing to different endpoint

---

### ❌ Issue 3: File not found

```
fullchain.crt not found
```

**Fix:**

* Recreated fullchain
* Used absolute path

---

### ❌ Issue 4: Secret not updated

**Cause:**

* Updated wrong namespace

**Fix:**

* Updated `wildcard-secret` in:

  * codadev
  * codaqa
  * codauat

---

### ❌ Issue 5: Certificate chain error

```
unable to verify first certificate
```

**Cause:**

* Missing intermediate certificate

**Fix:**

* Used fullchain

---

### ❌ Issue 6: ~ path issue

**Cause:**

* kubectl doesn't expand `~`

**Fix:**

* Used full path
